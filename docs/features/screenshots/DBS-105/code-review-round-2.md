- **Timestamp validation accepts trailing line terminators.** In JavaScript, `$` can match before a final line terminator, so `riskTimeNanoseconds("2025-01-01T00:00:00Z\n")` parses successfully instead of rejecting the malformed UTC timestamp. The subsequent date check only compares the first 19 characters, so it does not catch the suffix. Require the match to consume the entire string.
