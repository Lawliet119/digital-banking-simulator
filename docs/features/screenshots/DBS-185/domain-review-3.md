| 1 | should-fix | §2 "Lần chạy hợp lệ" (bullet 2), T3, §5 failure branch | The kill-timing rules use the task's `stoppedAt`. Expected path: `stop-task` at K+5, deregistration of a few seconds with delay 0, SIGTERM, then SIGKILL 2 s later, so the container exits around K+10.
