Claims I checked that hold, so no findings:
- **`getAllAndOverride`:** a method-level `@Roles` replaces the class-level one.
- **Guard to filter path:** an `HttpException` from a guard reaches `ProblemDetailsFilter` with `errorCode` passed through. Body keys are not filtered, so TC-51-25 is needed and is present.
- **`x-roles` precedence:** `ApiExtension` on the class does not override a method-level `x-roles` (swagger 11.4.7 `applyExtension`).
- **Injection:** `RolesGuard` needs only `Reflector`, so no export from `IdentityModule` is needed.
- **ID tokens:** an ID token is rejected through the `token_use` and `client_id` checks.
