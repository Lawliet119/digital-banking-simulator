# Ghi chú làm việc

> **Status:** Active · **Owner:** cả nhóm · **Verified against code:** n/a · **Cập nhật:** 2026-10-03

Nơi để **lập luận, thăm dò, ghi lại cuộc họp** — những thứ chưa phải quyết định. Khác với `docs/01–03` và `docs/adr/` (đã chốt hoặc đề xuất chính thức).

- Tên file: `YYYY-MM-DD-chu-de-ngan.md`.
- Mỗi ghi chú mở đầu bằng câu hỏi hoặc vấn đề, kết thúc bằng kết luận hoặc "chưa chốt, cần ai quyết".
- Khi chốt: chuyển thành ADR hoặc sửa tài liệu nguồn, rồi ghi link tới đó ở cuối ghi chú.
